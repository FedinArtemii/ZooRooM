# ZooRooM

Адаптивный сайт груминг-салона в Челябинске. На главной собраны услуги, информация о салоне, журнал, частые вопросы и способы записи. В демоверсии используются сгенерированные изображения. Анимации учитывают настройку уменьшенного движения.

[Сравнение двух дизайнов на GitHub Pages](https://fedinartemii.github.io/ZooRooM/versions/). Редакционный вариант доступен на главной, вариант с фирменным логотипом — по адресу `/brand/`.

## Запустить WordPress локально

Нужны Node.js 22+ и PHP 8.3+ с SQLite, mbstring, OpenSSL и Fileinfo. На Windows PHP ищется в PATH, а расширения по умолчанию загружаются из `C:/php/ext`. Для другой установки задайте `PHP_BIN` и при необходимости измените `extension_dir` в `.local/php.ini`.

```powershell
npm run setup
npm start
```

- Сайт — http://127.0.0.1:8096/
- Фирменный вариант — http://127.0.0.1:8096/brand/
- Страница сравнения — http://127.0.0.1:8096/versions/
- Админка — http://127.0.0.1:8096/wp-admin/
- Случайный пароль администратора — в локальном файле `.local/admin-credentials.txt`.

Установка загружает WordPress, SQLite Database Integration и WP-CLI. При повторном запуске она добавляет отсутствующие страницы фирменной версии и сравнения, сохраняя уже отредактированные страницы. `.local/` с базой и данными доступа исключён из Git.

## Редактирование и публикация

Оба варианта главной, страницу сравнения и три общие заметки можно редактировать в редакторе блоков WordPress. Иллюстрации можно заменить через блоки изображений. Шапка, меню и подвал находятся в файлах темы `theme/zooroom/`.

При запущенном WordPress выполните:

```powershell
npm run export
npm run verify
```

Экспорт берёт страницы из работающего WordPress, переносит ресурсы и переписывает ссылки для `/ZooRooM/`. Результат хранится в `docs/`. При отправке изменений в `main` GitHub Actions проверяет и публикует этот каталог. GitHub Pages обслуживает статическую витрину, админка работает в локальном WordPress.

## Перенос на WordPress-хостинг

Скопируйте `theme/zooroom/` в `wp-content/themes/`, активируйте тему и выполните в каталоге WordPress `wp eval-file /absolute/path/to/tools/seed.php` для первоначального заполнения. Для уже отредактированного сайта переносите базу и медиафайлы WordPress, чтобы сохранить изменения.

Демоверсия исключена из индексации. Перед рабочим запуском согласуйте контакты и цены с салоном, замените демонстрационные изображения фотографиями и включите индексацию в настройках WordPress.
